# Lodestar v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the harness, autoresearch loop and Alpaca paper trader described in `docs/superpowers/specs/2026-10-21-lodestar-v1-design.md`.

**Architecture:** A Python package `lodestar` holds the data layer, the locked harness and the paper trader. `research/` is the agent's workspace. `scripts/loop.sh` drives headless Claude Code. Strategy code always runs in a child process that only receives research data.

**Tech Stack:** Python 3.12, pandas 3, numpy, pyarrow, alpaca-py, python-dotenv, pytest.

Every task is test-first: write the failing test, run it, implement, run it again, then commit.
Run tests with `.venv/bin/pytest -q`.

### Task 8: Backtest with open-to-open execution and costs
Files: `lodestar/harness/backtest.py`, `tests/test_backtest.py`

- Commit: `feat(harness): open-to-open backtest with turnover costs`

### Task 9: Metrics

### Task 10: Deflated Sharpe ratio

- Commit: `feat(harness): deflated sharpe ratio`
